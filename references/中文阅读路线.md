# 中文阅读路线

[English](Reading_Guide_EN.md) | **简体中文**

建议先理解 Code Agent 工作负载，再学习正确性与安全边界，随后进入缓存系统、分层存储和压缩。不要从量化论文开始。

## 第一轮：建立研究对象

- **SWE-bench: Can Language Models Resolve Real-World GitHub Issues?**：真实仓库级问题与长上下文需求基准。
- **SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering**：工具闭环与 Agent 计算机接口基线。
- **OpenHands: An Open Platform for AI Software Developers as Generalist Agents**：通用软件开发 Agent 平台与轨迹结构。
- **Agentless: Demystifying LLM-based Software Engineering Agents**：非 Agent 式定位、修复和验证对照基线。
- **SWE-bench Goes Live!**：持续更新的真实仓库级评测与污染控制。
- **Multi-SWE-bench: A Multilingual Benchmark for Issue Resolving**：多语言仓库任务与 Agent 比较。
- **Training Software Engineering Agents and Verifiers with SWE-Gym**：软件工程 Agent 训练环境与轨迹数据。
- **ContextBench: A Benchmark for Context Retrieval in Coding Agents**：编码 Agent 上下文检索轨迹诊断。

## 第二轮：建立可复现系统基线

- **Efficient Memory Management for Large Language Model Serving with PagedAttention**：PagedAttention 与 GPU KV 内存管理基线。
- **SGLang: Efficient Execution of Structured Language Model Programs**：RadixAttention 与结构化生成复用基线。
- **Prompt Cache: Modular Attention Reuse for Low-Latency Inference**：模块化 Prompt 缓存与位置处理。
- **ChunkAttention: Efficient Self-Attention with Prefix-Aware KV Cache and Two-Phase Partition**：前缀感知共享与注意力内核。
- **CacheBlend: Fast Large Language Model Serving for RAG with Cached Knowledge Fusion**：非前缀缓存融合与选择性重计算。
- **EPIC: Efficient Position-Independent Caching for Serving Large Language Models**：位置无关缓存与线性边界修复。
- **Irminsul: MLA-Native Position-Independent Caching for Agentic LLM Serving**：面向 Agent 的 MLA 原生位置无关缓存。
- **Compute Or Load KV Cache? Why Not Both?**：读取缓存与重计算并行的收益边界。
- **MemServe: Context Caching for Disaggregated LLM Serving with Elastic Memory Pool**：分布式弹性内存池与跨实例缓存。
- **DistServe: Disaggregating Prefill and Decoding for Goodput-optimized Large Language Model Serving**：Prefill 与 Decode 解耦系统基线。
- **CacheGen: KV Cache Compression and Streaming for Fast Large Language Model Serving**：KV 压缩、流式传输与带宽自适应。
- **LMCache: An Efficient KV Cache Layer for Enterprise-Scale LLM Inference**：跨引擎、跨请求企业级 KV 缓存层。

## 第三轮：容量、质量与安全

- **KIVI: A Tuning-Free Asymmetric 2bit Quantization for KV Cache**：非对称 2-bit KV 量化基线。
- **KVQuant: Towards 10 Million Context Length LLM Inference with KV Cache Quantization**：超长上下文 KV 量化基线。
- **H$_2$O: Heavy-Hitter Oracle for Efficient Generative Inference of Large Language Models**：重频 Token 驱动的 KV 淘汰。
- **Scissorhands: Exploiting the Persistence of Importance Hypothesis for LLM KV Cache Compression at Test Time**：重要性持续性与固定预算缓存。
- **Efficient Streaming Language Models with Attention Sinks**：注意力 Sink 与流式长上下文。
- **SnapKV: LLM Knows What You are Looking for Before Generation**：生成前重要 Token 选择压缩。
- **PyramidKV: Dynamic KV Cache Compression based on Pyramidal Information Funneling**：跨层金字塔式缓存预算。
- **MiniCache: KV Cache Compression in Depth Dimension for Large Language Models**：跨层深度维 KV 合并。
- **DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model**：MLA 结构及 KV 表示变化。
- **DeepSeek-V3 Technical Report**：DeepSeek-V3 架构与 MLA 实现背景。
- **GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints**：GQA 结构与 KV 头共享。
- **LongBench: A Bilingual, Multitask Benchmark for Long Context Understanding**：长上下文多任务评测基准。

## 阅读纪律

- Stage 0-5 报告是冻结的实验协议，不是结果报告。
- Pilot 数据不得混入 Core 结果。
- 失败和负结果必须保留，不能删除或覆盖。
- 在线文档需要记录访问日期和版本；统一从 [官方技术资料入口](official_docs.md) 进入。
